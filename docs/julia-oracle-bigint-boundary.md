# Julia Oracle Lab BigInt boundary

This repository is authoritative for the `bigz-canonical-bytes` claim at boundary `shared-finite-kernel`. The dedicated known-answer probe emits canonical bytes for 0, 1, and -1000000001 using the production Mojo encoder.

`larsbx/julia-oracle-lab` independently recomputes these vectors. Its allowed verdicts do not include certificate acceptance or proof. A disagreement blocks promotion and creates an investigation obligation; it does not change which implementation owns the boundary.

The historical `NLAP-JT` repository may be recorded as source provenance for salvaged content, but its migrating name is not part of this stable boundary identifier.
